⚡ nanoGPT — How to Start

Train a baby GPT from scratch on your own machine, step by step.

macOS / Apple Silicon (M2) Python 3.12 + PyTorch Character-level GPT ~3 min CPU run

1 Install Python 3.12

PyTorch has no macOS wheels for Python 3.14 (your current default). Use Homebrew to install 3.12:

brew install python@3.12
Already done? If you already have a Python 3.10–3.12 environment with PyTorch, skip to Step 2.

2 Create a Virtual Environment

This keeps dependencies isolated to the project folder.

cd ~/Desktop/nanoGPT-master
/opt/homebrew/opt/python@3.12/bin/python3 -m venv .venv
source .venv/bin/activate
Note: Your prompt should now show (.venv).

3 Install Dependencies

pip install torch numpy tiktoken transformers datasets wandb tqdm requests
Apple Silicon tip: pip will automatically pick the mps-capable macOS ARM build of PyTorch. Verify with: 
python -c "import torch; print(torch.__version__, torch.backends.mps.is_available())"

4 Prepare the Dataset

Downloads the 1MB tiny-shakespeare text and builds train.bin, val.bin and meta.pkl.

python data/shakespeare_char/prepare.py

Expected output (your dataset stats):

length of dataset in characters: 1,115,394
all the unique characters:  !$&',-.3:;?ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz
vocab size: 65
train has 1,003,854 tokens
val has 111,540 tokens

5 Train a Baby GPT

Use --device=mps to run on the M2's on-chip GPU (2–3× faster), or --device=cpu if you prefer.

python train.py config/train_shakespeare_char.py \
  --device=mps \
  --compile=False \
  --max_iters=2000 \
  --eval_iters=20 \
  --log_interval=10 \
  --block_size=64 \
  --batch_size=12 \
  --n_layer=4 --n_head=4 --n_embd=128 \
  --dropout=0.0

Runs in ~3 minutes. The best checkpoint is saved to out-shakespeare-char/ckpt.pt.

The stock config trains a 6-layer / 6-head / 384-embedding model to val loss ≈ 1.47 in ~3 minutes on an A100.

python train.py config/train_shakespeare_char.py

6 Sample from Your Model

python sample.py --out_dir=out-shakespeare-char --device=mps

Generates 10 samples of up to 500 characters each. Expect play-like but nonsensical text for a small model — that's the magic of it.

7 Understand the Stats You'll See

During training, train.py prints these stats every log_interval iterations:

iter 100: loss 2.0314, time 123.45ms, mfu 0.52%
StatMeaningGood Sign
iter Current training iteration (step) number Climbing steadily
loss Cross-entropy loss on the current training batch Decreasing over time
time Wall-clock time per iteration (ms) Lower = faster
mfu Model FLOPs Utilization — how much of the GPU's peak compute you're using Higher = better (A100 peak = 312 TFLOPS)

Every eval_interval iterations, you also get train/val loss estimates:

step 0: train loss 4.0552, val loss 4.0451
step 250: train loss 2.0312, val loss 2.1034
step 500: train loss 1.7455, val loss 1.9081
Pro tip: If val loss starts climbing while train loss keeps falling, your model is overfitting — reduce max_iters or raise dropout.

8 Track Stats with Weights & Biases

nanoGPT ships with optional wandb logging. The --wandb_log=True flag logs train/loss, val/loss, lr, and mfu to an interactive dashboard:

python train.py config/train_shakespeare_char.py --device=mps --compile=False \
  --wandb_log=True --wandb_project=shakespeare-char --wandb_run_name=my-first-gpt

9 Next-Level: Reproduce GPT-2 (124M)

For a real GPT-2-scale run you need serious hardware (8× A100). The commands below are from the README for reference:

# 1. Download + tokenize OpenWebText (~17GB train.bin)
python data/openwebtext/prepare.py

# 2. Reproduce GPT-2 124M (8× A100, ~4 days)
torchrun --standalone --nproc_per_node=8 train.py config/train_gpt2.py
# Evaluate OpenAI pretrained checkpoints as baselines:
python train.py config/eval_gpt2.py        # 124M
python train.py config/eval_gpt2_medium.py  # 350M
python train.py config/eval_gpt2_large.py   # 774M
python train.py config/eval_gpt2_xl.py      # 1558M
